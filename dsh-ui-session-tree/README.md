# dsh-ui-session-tree

DeepSeek Harness 的**会话树插件**:把 fork 出来的分支以 git-graph 式的纵向树形结构呈现在右侧面板里,支持在任意一轮对话上创建新分支、以及 Claude Code 式的"回退到此轮"(rewind)。

## 为什么

DSH 的会话日志是唯一真相源(append-only 事件流),fork 会把父会话前缀复制进子会话(头里有 `parentSession` + `seedLength`)。但官方 UI 只把这条血缘渲染成**缩进的平铺列表**——分支从哪分出来、兄弟分支有哪些,完全不可见。本插件把它显式化成一棵可交互的树。

## 功能

- **只显示当前会话所在的分支树**(含其全部子孙分支):切换会话时树自动跟随切换;未打开会话时显示提示。不再罗列所有会话根。
- **右侧树面板**:侧栏底部"🌳 会话树"按钮开关;树从上往下生长,主干**居中**、一级分支按兄弟次序**左右交替分列**以保持左右平衡(孙分支继承父侧向外生长,子树不跨主干;无左分支时布局与单侧版完全一致),车道块在面板内自动水平居中,打开面板时当前分支自动滚动到视口中央。面板打开时会话区**让位而非被遮盖**(见下方注入点说明)。
- **画布零文字,悬浮显示一切内容**:树图形区域只有圆点(对话轮)、空心环(分支头)和连线;画布右侧**预留固定动作区**(60px),hover 出现的快捷按钮永不遮挡车道节点;轮次的**完整用户消息文本**、分支头的标题/时间、运行状态全部 hover 节点时在气泡里显示(气泡默认**紧贴所悬停行的下缘**(零间隙,像挂在行下的弹出菜单)——任何视觉间隙都是下一行的裸露区域,鼠标穿行时会抢走 hover 导致气泡"逃跑";底部空间不足时翻至上方,同样紧贴。长文本气泡内可滚动,视口定位不被面板滚动裁剪,右缘自动左翻,窄视口钳制)。气泡内嵌动作按钮,鼠标可移入气泡操作;离开行/气泡均有 400ms 缓冲,穿行气泡去别的行不会闪烁。
- **车道色系(视觉签名)**:每条分支车道拥有稳定色相(8 色循环,按**到主干的距离**取色——右侧车道从色环头部、镜像的左侧车道从尾部,跨主干相邻车道不撞色;主干石墨灰,git 惯例),贯穿该车道的竖线、分叉曲线、轮次圆点、hover 行色带与气泡左缘导轨;进入当前会话的曲线加粗。画布带每行一条 4% 透明度的参考细线;面板滑入动画 180ms,`prefers-reduced-motion` 下全部关闭。
- **⑂ 从此处创建分支**:hover 任意一轮 → 分叉。底层是官方 `session.fork({sessionId, atSeq})`(atSeq 锚定该轮 `turn/end`),完成后自动打开子会话。
- **⇢ 移交(跨分支结果回流,拖到目标车道)**:**拖放定向**——按住任意节点的圆点/空心环拖到另一条车道松开:空心环=整支成果,轮次圆点=截至该轮(含)。拖动超过 8px 后进入移交:源车道保持高亮、其它行淡出,指针跟着一条贝塞尔鬼影线,目标车道加粗、目标行发光,光标旁提示「松手移交到「某分支」」。松开弹出确认条(源/区间/目标已填好,下拉仍可改目标)。**划区间**——单击选源(不拖),同分支再点另一个节点把两点之间划为区间(含两端,空心环=到最新),然后再把源拖到目标车道。**点击兜底**(键盘/点不准):气泡里「选为移交源」+ 目标气泡「移交到此分支」,与拖放走同一条确认条。把源相对目标的**差异轮次**(源区间内 endSeq 集合 − 目标轮次集合,共同继承段自动抵消)整理成一条消息——含每轮用户提问、助手结论(排除思考块)与工具使用统计——经 `session.prompt(mode:"queue")` 发给目标分支,**由其模型就地消化吸收并继续任务**(日志 append-only 不支持真合并,这是"模型语义合并")。确认条实时显示差异轮数,0 轮禁用确认;载荷按轮截断、总量上限 3 万字,超限优先保留靠后的轮次(结果在尾部)。Esc 取消拖动;松在空白处保留选源;切换谱系自动清空。
- **⟲ 撤回此轮(Claude Code / pi 式撤回)**:**任意分支**的任意已完成轮次上(不限当前会话),把该轮(含助手回复)及其之后的所有消息**从该分支中撤掉**,回到"刚要发送这条消息"的状态。实现 = 在该轮**之前**切(`atSeq = startSeq - 1`,不含该轮)fork 该分支 + **继承该分支标题**(无 "(1)" 后缀,读起来还是同一个会话)+ **自动归档被撤掉的旧分支**(软删除,日志保留、可恢复——与 Claude Code 隐藏旧 transcript 同理;源会话运行中时跳过归档)+ 打开撤回结果(视图随之切过去)。⑂ 分叉按钮保持"含该轮"语义,两个动作互补:⑂ = 从这轮之后岔路,⟲ = 撤掉这轮。首轮(`startSeq = 0`)之前无锚点,不提供撤回。
- **🗑 删除该分支**:分支头上的删除入口,面板内嵌**两步确认条**(不用原生 confirm,不阻塞渲染);走 `workspace.archiveSession` 软删除——从所有列表隐藏、日志保留、可恢复。已归档会话通过 workspaces 域的 `archivedSessionIds` 从树中过滤(与官方列表一致)。**删除当前所在分支后自动落回它分叉出来的那支**(即主支):归档前先沿原始列表的 parentId 链解析最近的存活祖先(中间祖先已归档则继续上溯,环安全),归档成功即 `open()` 该祖先,自然停在其最新轮次;删除非当前分支不动当前视图。
- 运行中的会话仅禁用**删除/归档**;**分叉/撤回不受运行状态限制**——append-only 日志下已完成轮次的前缀不可变,切点快照天然一致(服务端 fork 也只要求锚点是已完成的 `turn/end`,并无运行状态检查);进行中的轮(`turn/end` 未落)本就无动作按钮(撤回用的锚点是其 `startSeq - 1`,落在上一轮的 `turn/end` 上,同样安全);撤回时若源会话运行中,跳过对它的自动归档。键盘可达(行可 Tab 聚焦,Enter 打开,Esc 关气泡,focus 时显示动作按钮)。

## 机制(全部 client 侧,host 半边为空)

| 数据 | 来源 |
| --- | --- |
| 树拓扑(父子关系) | `session.list` 摘要的 `parentId`(过滤 blank / subagent / archived;**父被归档的子分支上挂到最近存活祖先**——撤回会自动归档源分支、🗑 可能删中段分支,上挂保证撤回结果仍挂回分叉点、子孙不脱离谱系;无存活祖先才降级为根;parent 环提升为根,谱系永不静默丢失) |
| 每分支的轮次 | `session.history` 分页拉全量事件(游标严格递减防护 + 页数上限),fold 出 `turn/start`→`turn/end` 区间与首条用户消息 |
| 自有轮次 / 分叉锚点 | **按 seq 对齐,不看 seed 标记**:fork 拷贝父日志前缀时保留原始 seq,子会话中"最后一个 endSeq 与父干轮次重合的 turn/end"即分叉点,其后为自有轮次。(`session/end-seed` 不能用于此判断——compaction 从 seed 重建会话时同样会写该标记,旧实现据此把压缩过的会话整棵折叠成单头节点。)根/孤儿分支全部轮次均自有 |
| 分叉/撤回 | 分叉:`ctx.sessions.fork({sessionId, atSeq: endSeq, increaseTitle: true})`(含该轮)→ `open(childId)`;撤回:`fork({atSeq: startSeq - 1, increaseTitle: false})` → `sessions.rename` 继承原标题 → `workspace.archiveSession` 归档旧支 → `open(childId)`(运行中的源跳过归档) |
| 移交 | 拖放(或点击选源)→ 节点差集(`deltaTurnsOf`:源轮次 endSeq 集合 − 目标轮次集合)→ `buildHandoffText` 组装差异转录 + 消化指令 → 确认条 `api.sessions.prompt({sessionId: 目标, mode:"queue", content})`,由目标会话当前模型消化 |
| 删除 | `workspace.archiveSession({sessionId})`(两步确认) |

懒加载按会话粒度进行:同一时刻每个会话至多一个在途请求(inflight 去重),结果按 `id@updatedAt@refreshTick` 值键缓存并自动淘汰同 id 旧键——列表推送导致的森林重建不会触发重复请求。面板关闭时不展开、不拉取。

UI 注入点均为**增量 slot**,不替换任何官方组件:

- `shell.overlay`(list 型)—— 面板本体(自带样式,主题走 `--dsw-alias-*` tokens)。面板**停靠而非覆盖**:打开时按结构查找到 overlay 层背后的 grid 外壳(宿主 class 是构建哈希,不可硬编码),给其打上与面板实测宽度一致的内联 `padding-right`(随窗口 resize 重算,关闭/卸载还原,宿主自身的内联样式不受影响),会话列据此重新排版让位;找不到 grid 外壳时退回覆盖式 overlay。
- `sidebar.footer.action`(list 型)—— 底部开关按钮(窄栏只显示图标)。该 slot 宿主容器是**不换行的横向 flex 行**,与其他全宽条目(如 dsh-usage-stats 的用量徽章)同注册会互相挤出可视区;插件挂载时会给宿主行打上内联 `flex-wrap: wrap` 并以 `flex:0 0 100%` 独占一行(卸载时还原),宽栏整行按钮、窄栏图标居中。

## 已知边界

- **撤回底层仍是"新分支"而非原地截断**:DSH 日志按设计 append-only(事件序列连续性是不变量),原地 rewind 会破坏日志完整性,也没有任何 truncate API;插件的撤回 = 切在该轮之前的 self-fork + 继承原标题 + 自动归档旧支,三层叠加在 UX 上等价于"原地撤回"。旧分支日志完整保留,可从归档恢复;若撤回时源会话正在运行,归档跳过(旧分支保留在树中,直到它跑完)。
- 子分支的分叉点落在其父的**继承段**内(父自己也是 fork、且分叉发生在继承前缀内)也能正确挂载:seq 对齐天然处理嵌套继承——子会话拷贝的是父的完整日志前缀(含父从祖父继承的轮次),匹配集合取父的**全部**轮次而非仅父的自有轮次。
- 撤回/归档产生的"父已隐藏"分支**上挂到最近存活祖先**(seq 对齐天然重锚:撤回结果只含分叉点之前的历史,挂回后恰好呈现为分叉点处的新环);无任何存活祖先才自成根,此时若它 fork 后还没有新轮次,画布上就是一个单独的环。
- 标题取 `session.list` 行的 `title`/`displayTitle`,取不到则退化用首个用户消息前 64 字。
- 面板开合状态存 `localStorage`(key `dsh-session-tree:open`)。
- 个别历史会话若日志损坏(如 seq 断档),树会显示错误条但不影响其他分支。
