# 索隆主题 · dsh-zoro-channel-theme

参考 Joi 0.1.14 的 Theme token / ConfigForm / appearance slot 接入方式，独立实现的索隆主题。

- **三刀流**：刀装墨绿、耳坠金与浅色纸面。
- **阎魔**：紫黑底色、淡紫强调与金色细节。
- 两套均支持浅色、深色、跟随系统；可切回原生外观。
- 新会话右侧展示透明全身立绘，随窗口缩放；窗口缩到最小也保留 120px 宽的最小立绘，右侧空白不够时首页内容只让出差额。
- 左上角为索隆与桑尼号双角色，首页标题上方显示索隆 Q 版。
- 与 dsh-claude-style 的侧栏搜索框共存：搜索框用「独立」样式时占自己一行（插画横幅下、「新会话」上），配色跟随当前衣装；「覆盖品牌」样式下插画会盖住那个按钮，主题直接移除它，避免留下看不见却能点中的幽灵搜索框。
- 对话输入框上沿左侧桑尼号、右侧索隆，提供待机、处理中、完成、出错四套状态表情；为角色预留空间，保持消息可读。
- 设置里的「角色插画」开关统一控制首页与对话页的装饰图。
- 设置 → 通用 → 索隆·换装，可以切换配色、明暗和立绘。
- 自带 PNG 内嵌到客户端，不依赖外链图床。

## 构建与安装

```sh
node scripts/build.mjs
node --test test/*.test.mjs
python3 scripts/install.py
```

安装到 `~/.dsh/profiles/desktop`。安装脚本备份配置并注册本地包，保留现有插件开关；首次安装默认不启用。在插件页关闭 Joi、启用索隆即可切换。切回 Joi 时关闭索隆、启用 Joi。

0.1.5 修复：立绘设最小宽度 120px，窗口缩到 DSH 允许的最小尺寸（520×600）也不再收起。右侧空白不够时，首页内容列只让出差额（最小窗口里内容约 376px），宽窗口不让位；只有在最小窗口里手动展开侧栏、内容不足 320px 时才收起立绘。

0.1.4 修复：立绘不再固定 340×620，高度跟窗口走、宽度取首页内容右侧的空白；dsh-claude-style「工作台」首页不再额外让出 260px 右内边距，用量面板和输入框恢复原宽度。该版面下侧栏展开、窗口宽度低于约 1320px 时右侧放不下立绘，会自动收起。

0.1.3 修复：侧栏插画横幅盖住 dsh-claude-style 的侧栏搜索框（搜索框打不开）。设置 → 侧栏 → 搜索框样式改为「独立」后，搜索框排在横幅与「新会话」之间，不再重叠。

0.1.2 补齐：首页 Q 版、侧栏双角色、对话页双伙伴与四种状态表情，并修复输入区背景遮挡伙伴的问题。

0.1.1 修复：移除旧安装器写入的强制停用 Joi / 额外插入索隆组件的覆盖配置，主题生命周期完全由插件管理器控制。

## 恢复

将安装脚本打印的 `zoro-theme-backup-*` 目录里的 package.json / cordis.patch.yml 复制回 desktop profile，重启 DSH。原 Joi 插件和配置保留在本机。

## 立绘

`assets/zoro-standing.png` 是内置 image_gen 生成的 RGBA 全身图；提示词见 `assets/prompt.txt`。图像主体为索隆，绿色长袍、三刀、金耳坠，透明背景。使用自己的 PNG 替换此文件后重新构建即可换图。

`assets/zoro-chibi-sheet.png` 和 `assets/sunny-chibi-sheet.png` 为透明 2×2 精灵表，依次排列待机、完成、处理中、出错。使用内置 image_gen 生成；提示词见 `assets/companions-prompts.txt`。

第三方代码和角色素材说明见 THIRD_PARTY_NOTICES.md。插件仅为非官方同人主题。
